# Spendio

ไอคอนและโลโก้ของ Spendio แอพบันทึกรายรับ-รายจ่ายส่วนตัว (Google Apps Script web app)

<img src="icons/logo-full.png" width="420" alt="Spendio — Spend Smart. Live Better.">

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `icons/icon-512.png` | ไอคอนหลัก 512×512 (ใส่ลิงก์ไฟล์นี้ใน `CFG.ICON_URL` ของ Code.gs) |
| `icons/icon-192.png` | ไอคอนหน้าจอหลักบน Android |
| `icons/apple-touch-icon-180.png` | ไอคอนหน้าจอหลักบน iPhone |
| `icons/favicon-32.png` | ไอคอนแท็บเบราว์เซอร์ |
| `icons/icon-rounded-512.png` | ไอคอนมุมมน พื้นขาว |
| `icons/logo-full.png` | โลโก้เต็มพร้อมชื่อและคำโปรย พื้นโปร่งใส |
| `icons/logo-mark.png` | สัญลักษณ์วงแหวนอย่างเดียว พื้นโปร่งใส |

ลิงก์ไอคอนหลัก: `https://raw.githubusercontent.com/Proparn/Spendio/main/icons/icon-512.png`
